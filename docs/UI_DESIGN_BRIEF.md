# UI 设计需求书(给外部 UI/AI 设计工具用)

把本文整段贴给设计工具,作为"产品背景 + 屏幕清单 + 约束"。设计稿定稿后,交给开发实现(见最后"交付物")。

## 1. 产品背景

- 名称:小翻译 · Lilla Tolken。**学龄前儿童(约 3–6 岁)用的中文 ↔ 瑞典语按键说话翻译器**,在 iPhone Safari 里运行(竖屏)。
- 使用者:孩子自己按按钮;**不识字**,几乎不依赖文字。旁边有成人,成人才读文字、处理问题。
- 核心感受:温暖、安全、好玩、不吓人。一次只做一件事,一个屏幕只有 1–2 个主要按钮。
- 两个方向:🇨🇳→🇸🇪(中文说,瑞典语出)、🇸🇪→🇨🇳。
- 流程(每一步都是一个屏幕,见第 3 节):按住说话 → 听 → 想 → (必要时问一个小问题)→ **确认意思(✅/❌)** → 翻译 → 播放声音。

## 2. 硬性约束(设计稿必须满足)

- **画板尺寸**:同时出 **390×844(iPhone 14)** 和 **375×667(iPhone SE,带 Safari 工具栏后可用高度约 553)** 两套;宽度最窄 320。内容必须**不横向溢出**,高度不够时允许纵向滚动,但**主按钮必须一眼可见,不能被切掉**。
- 安全区:顶部刘海、底部 Home 条留白(约 34px)。
- **触控目标** ≥ 64pt,主按钮 ≥ 96pt;按钮之间间距 ≥ 12pt。主操作放在屏幕**下半部**(单手拇指区)。
- **图标 / 颜色 / 动画优先于文字**;任何功能不能只靠读字才能操作。文字只给成人看,中文和瑞典语都要放得下(瑞典语单词较长)。
- 字体:只能用 iOS 系统字体(SF Pro Rounded / PingFang SC),如果要用其他字体,必须是可免费商用且含简体中文的,并说明来源。
- 对比度:文字与背景 ≥ 4.5:1;不要只用颜色区分状态(配图标/形状)。
- 无需暗色模式。无登录、无菜单、无多层导航。
- 动画只用简单 CSS 能实现的(缩放、脉动、摇摆、进度环),不要依赖视频或 Lottie 大文件。
- 插画/图标请提供 **SVG**(或透明 PNG @3x),单个文件尽量小;不要含有真人儿童照片。
- 页面里**不显示**孩子的任何识别文字(给孩子的屏幕上不放转写文字,成人信息折叠在"👁 For adults"里)。

## 3. 屏幕清单(每个都要出稿,并标出各状态)

每一屏的"可点击元素"是固定的(由程序状态机决定),设计可以改外观和排版,**不要增删功能**。

| # | 屏幕 | 出现时机 | 主要元素 / 状态 |
|---|---|---|---|
| 0 | 顶栏(所有屏幕共用) | 一直 | 左:取消(任务中才有);中:标题或方向旗帜;右:切换方向 ⇄(任务中)+ 成人设置 ⚙(成人用,尽量不显眼) |
| 1 | **首页** | 空闲 | 两个超大按钮:🇨🇳🎤➜🇸🇪 / 🇸🇪🎤➜🇨🇳。可有吉祥物。底部可出现成人警告(需 HTTPS / 不支持录音) |
| 2 | **录音中** | 按下后 | 3 个状态:①提示音播放中("现在可以说啦") ②**正在听**:30 秒倒计时环 + 大号数字 + 大"停止"按钮,最后 5 秒变警示色 ③处理中(灰色禁用)。顶部小圆点表示第几段(最多 3 段),可有"澄清 ❓ / 修改 ✏️"小标记 |
| 3 | **继续还是结束** | 一段录完后 | 已录段数小圆点;两个按钮:🎤➕ 继续说 / ✅ 说完了 |
| 4 | **忙碌/思考中** | 等待 AI | 4 种阶段:听 / 理解 / 翻译 / 准备声音。一个会动的小角色或动画 + 简短文字(成人读) |
| 5 | **小问题(澄清)** | 需要追问 | 播放一个简短问题的声音;🔊 重放按钮(大);🎤 回答按钮(超大)。问题文字作为成人可读的小字 |
| 6 | **确认意思** | 翻译前必须经过 | 先播放"你的意思是…?";🔊 重放;**✅ 对 / ❌ 不对** 两个超大按钮(绿/红,不只靠颜色) |
| 7 | **结果** | 翻译完成 | 状态:①准备中(🔊 Play 脉动)②语音生成失败(重试 / 只看文字)③已送达(Replay + ➕新一轮 + 🎤🔁重录)。成人文字卡:原文 + 译文(瑞典语/中文,长句要能折行) |
| 8 | **切换方向确认** | 点 ⇄ | 🔄 + 目标方向旗帜;两个按钮:切换 / 继续当前 |
| 9 | **出错** | 网络/麦克风/模型出错 | ⚠️ + 重试(大)+ 取消;成人文字说明原因(权限被拒、网络、超时、未配置) |
| 10 | **无法完成(兜底)** | 追问满 3 次 / 纠正满 2 次 / 反复没听到 | 🤷 + 重新开始 + 取消;成人文字说明 |
| 11 | **没听清** | 识别为空 | 👂❓ + 大"再说一遍"按钮,剩余次数给成人看 |

(成人开发者面板 ⚙ 不需要设计,保持现状。)

## 4. 现有设计语言(可参考也可推翻)

- 背景暖米色 `#FFF7E6`;主色:红 `#EF4444`(开始/停止)、蓝 `#3B82F6`、绿 `#22C55E`(确认)、橙 `#F59E0B`(重试)、紫 `#8B5CF6`(播放)、灰 `#94A3B8`。
- 圆角 28px 的大按钮,底部有 6px 厚度阴影(按下会下沉)。
- 我认为**当前效果不够好**:太像"成人工具",缺少角色和情感、布局不够聚焦。希望新设计更有童趣(但不幼稚到分散注意力),并且层次更清晰。

## 5. 请设计工具输出

1. 上面 12 项屏幕 × 其状态的高保真稿,两种画板尺寸。
2. 一页**设计规范**:颜色、字号阶梯、间距、圆角、按钮(含 normal / pressed / disabled / pulse)、阴影。
3. 图标与插画清单及文件(SVG)。
4. 动画说明(哪个元素、做什么、时长、缓动)。

## 6. 交付给开发的格式(从方便到最好)

1. **Figma 链接**(给查看权限)+ 每个屏幕导出的 **PNG @2x**(两种尺寸)。**最好**。
2. 或者工具导出的 **HTML/CSS/React 代码**(如果有),连同截图一起给。代码只作为视觉参考,我会用现有 React 组件重写,不会直接拼进去。
3. 设计规范(第 5 节第 2 项)用文字/表格或图片都行。
4. 素材:`assets/` 文件夹(SVG/PNG),注明哪个文件用在哪里。

开发实现时我会:**保持状态机、对话策略、全部 `data-testid` 和自动化测试不变**,只替换 `apps/web/src/ui/*` 和样式;在 375×553、375×667、390×844、320 宽上逐屏截图核对,不溢出。
