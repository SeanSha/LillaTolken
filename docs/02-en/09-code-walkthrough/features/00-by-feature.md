# By feature

This is where document 09 enters a concrete action. [Back to the index](../00-start-here.md).

A file page answers what each section of that file does. This set answers a different question: when someone completes one action, which files run, and in what order.

Inside every page the order is the same: the machine JSON at that moment, then who calls whom, then the steps. Read item 1 through item 9. The spoken example is 「我想去厕所。」 The card example is a photo of a cup.

## Order

1. [Speak Chinese, hear Swedish](01-speak-chinese-hear-swedish.md). The meaning is clear and the child taps yes. This is the main path.
2. [Chinese was not clear](02-chinese-was-not-clear.md). A follow-up question, or the child taps no.
3. [Speak Swedish, hear Chinese](03-speak-swedish-hear-chinese.md). Interpretation and confirmation are skipped.
4. [Switch direction in the middle](04-switch-direction-mid-turn.md).
5. [Not heard, an error, or the limit](05-not-heard-error-or-limit.md).
6. [Photograph an object into a card](06-photo-into-a-card.md).
7. [Open a card and hear the word](07-open-a-card-and-speak-it.md).
8. [How this turn shows up in the monitor](08-how-this-turn-shows-in-the-monitor.md).
9. [Switch to cloud or local](09-switch-to-cloud-or-local.md). The buttons stay the same. The selected server implementation changes.
