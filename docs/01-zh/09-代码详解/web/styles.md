# `apps/web/src/styles.css`

源码：[styles.css](../../../../apps/web/src/styles.css)

儿童界面的外观。颜色和圆角来自设计稿，布局改成了「顶栏固定、中间可滚动」。`/monitor` 不加载这份文件，监控有自己的样式。

## 颜色和整页

`:root` 里是墨蓝字、奶油底、珊瑚红、天蓝、薄荷绿。按钮用这些变量，不在组件里写死一长串色值。

`html`、`body`、`#root` 撑满屏幕，背景是浅黄。`overscroll-behavior: none` 让手机拉到顶时不要露出浏览器的橡皮筋空白。

例子：首页的大按钮是珊瑚红 `.big-button`。录音时同一颗按钮换成停止的样子，颜色类跟着状态变，组件不用自己算色。

## 顶栏

`.topbar` 一直停在上面：返回、声音、预设小标签。`.top-action.is-hidden` 在不该出现的屏幕上把按钮收起来，而不是删掉占位，避免画面跳动。

## 屏幕区

`.main` 是可滚动的中间。`.screen` 至少和内容一样高，小手机上字和按钮不会被裁掉。词卡学习页和家长页用 `.vocab-learn`、`.vocab-parent`，顶栏仍然在。

## 吉祥物和按钮

`.mascot` 画那只蓝色的孩子形象：身体、耳朵、眼睛、腮红。`.big-button` 是给孩子按的大圆钮。录音、思考、提问、确认、结果、换方向，各有一块注释隔开，类名和 `screens.tsx` 里的屏幕对应。

## 小屏幕和成人层

大约从 754 行起，短手机（iPhone SE、横屏、Safari 工具栏）把字号和间距收小。再往下是成人说明、警告条，以及齿轮里的开发面板。最后一大段是拍照词卡：取景、候选、草稿、画廊。

例子：在 iPhone SE 上打开确认页。「你是说：我想去厕所，对吗？」和「是 / 不是」仍在屏幕里，不会被顶栏盖住。这是 `.screen` 和短屏规则一起做的，不是状态机的事。
