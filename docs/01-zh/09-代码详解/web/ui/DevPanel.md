# `apps/web/src/ui/DevPanel.tsx`

源码：[DevPanel.tsx](../../../../../apps/web/src/ui/DevPanel.tsx)

齿轮后面的成人面板。儿童主路径不靠它。

可以换 mock 场景、换麦克风模式、看当前是不是安全网页、导出评估 CSV。改预设会调用状态机的 `SET_PRESET`，只有空闲时才生效。

例子：要在手机上试权限，又不想花钱。把麦克风改成「真麦克风 + 剧本文本」，预设仍是 mock。点停止后，识别文本还是剧本，但浏览器会真的问麦克风权限。

云端预设需要勾过「只使用成人或合成语音」。导出 CSV 要先在 `/monitor` 登录。
