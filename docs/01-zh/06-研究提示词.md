## 和对话规则怎么配合

语言模型返回的是结构化的理解或翻译。程序先校验，再用 XState 决定下一步允许做什么。理解只可能是三种决定之一：`PROPOSE_MEANING`、`ASK_CLARIFICATION`、`UNRESOLVED`。澄清、纠正、确认、换方向和送达，由状态机管理，不由模型自由发挥。

运行时的对话上下文是另外传进去的，例如 `dialogueInputs`、`remainingClarifications`、`previousDelivered`。上面固定的文件记录的是提示词和 schema，不是测试时的录音稿。

## 范围和可复现性

研究记录把理解提示词标为修订 **p3**。上面固定的源文件复现的就是这一版，适合读者查看。评估材料没有留下完整的、已测试过的提交号，也没有留下全部第三方语音会话设置。因此不要把那个提交说成「已经核对过的、完整的实验运行快照」。

本页没有参与者的录音、儿童个人信息、密钥或 API key。
